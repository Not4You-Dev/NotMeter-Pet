# NotMeter Pet Map Assets

Static Global client assets used by [NotMeter Pet Insight Map](https://notmeter.com/pet-tracker.html).

- Verteron, Altgard and Chaotic Lower Reshanta map backgrounds and authored monster / Kibelisk positions.
- 200 pet definitions, client icons, growth requirements and verified acquisition sources.
- Eight official client languages; website interface translations are maintained in the main NotMeter website.
- No user profiles, exported pet codes, game packets or credentials are stored here.

Authored positions describe possible spawn locations, not live monster presence. Client assets remain the property of their respective owners.

Asset format: `manifest.json`, `maps/*.webp`, `icons/*.png`.

Projection derives from each client map’s tile-plane bounds. Monster-to-pet mapping includes both direct soul items and ordinary soul-item loot entries. Confirmed field-boss flags are attached to individual NPC spawn points.
